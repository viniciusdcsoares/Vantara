A multi-source scraping orchestrator designed to collect and consolidate data from YouTube, Bluesky, and NewsAPI.

## Features
- **Integrated Orchestrator**: Run multiple scrapers at once via `main.py`.
- **YouTube Scraper**: Extracts videos, metadata, and transcripts.
- **Bluesky Scraper**: Fetches recent posts and threads.
- **NewsAPI Scraper**: Collects articles with source diversity.

## Setup
1. **Environment**: Use Python 3.12.
2. **Installation**: pip install -r requirements.txt
