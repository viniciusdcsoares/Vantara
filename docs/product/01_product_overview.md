# Product Overview — Political Intelligence Platform

## Purpose

This product is a political communication intelligence platform for candidates, especially federal deputy candidates in Brazil. It combines narrative monitoring, social media performance analysis, strategic planning, and daily recommendations.

The practical goal is simple:

- show what is happening in the public debate
- show what is working in the candidate's own channels
- identify risks, missed opportunities, and competitor moves
- recommend what the candidate should say today, why, and in which format

This is not a generic social media dashboard. It is a strategic campaign copilot.

---

## Core Value Proposition

The system helps campaigns answer five recurring questions:

1. What narratives are growing right now?
2. Which of those matter for this candidate?
3. What is working on the candidate's own social media?
4. What are competitors and allies doing?
5. What should the candidate post or reinforce today?

The product should feel like a mix of:

- narrative radar
- campaign strategist
- social performance analyst
- daily briefing assistant

## Core Product Modules

### 1. Narrative Radar

Tracks:
- emerging narratives
- dominant topics
- acceleration of discourse
- who is pushing each topic
- narrative direction

Sources can include:
- YouTube
- Instagram
- TikTok
- X / Twitter
- news feeds
- Google Trends
- monitored public political accounts

### 2. Strategic Planning Layer

Crosses:
- detected narratives
- candidate profile
- campaign positioning
- allies
- competitors
- target audiences

Outputs:
- opportunities
- risks
- recommended positioning
- daily communication priorities

### 3. Social Media Performance Analysis

Analyzes candidate-owned accounts, especially:
- YouTube
- Instagram
- TikTok

Shows:
- best-performing posts
- worst-performing posts
- themes that generate the most engagement
- formats that work best
- performance trends by platform

### 4. Competitor and Ally Monitoring

Tracks:
- what competitors are saying
- when competitors dominate a topic
- when allies publish content worth amplifying

### 5. Daily Recommendation Engine

Produces:
- daily briefing
- suggested topics
- suggested formats
- narrative justification
- urgency level

- communication tone
- political archetype

### Campaign strategy
- main thesis
- priority themes
- desired public perception
- target audiences
- sensitive topics

- preferred arguments
- preferred formats

### Political network
- main allies
- main competitors
- themes shared with allies
- themes dominated by competitors

## MVP Goal

The MVP does not need to be perfect. It needs to do four things well enough to sell:

1. collect relevant data
2. detect useful narratives
3. analyze the candidate's social performance
4. generate daily strategic recommendations

The first commercial version should already justify a premium monthly contract because it saves time, reduces improvisation, and improves communication decisions.

---

## Pricing Logic

The product should be sold as strategic intelligence, not as a dashboard.

Recommended framing:
- campaign intelligence system
- communication copilot
- daily political narrative radar

The target value perception is high-ticket because the product supports real campaign decisions.

---

## Product Design Principles

- prioritize actionability over complexity
- avoid vanity metrics
- reduce cognitive load for the user
- make recommendations explicit and justified
- use WhatsApp as a primary delivery layer
- keep the dashboard as the command center

---

## AI Coding-First Operating Principle

This project should be developed with an AI coding-first approach.

That means:
- AI generates a large share of the initial implementation
- human developers review, adapt, simplify, and finish
- the internal team focuses on front-end quality, edge cases, debugging, and business-specific corrections

The documentation should therefore be structured for:
- code generation
- agent-driven development
- promptable context
- modular engineering execution
